Detailed changelog of everything shipped, in progress, and planned for Kaynos.

## Recent highlights

### May 2026

-   Multi-video sessions and classes: attach more than one video to the same session or class and switch between them in the player.
-   Self-serve email change with verification: update your sign-in email from **Profile → Email address** and confirm via a link sent to the new address.
-   Mobile nav redesign: profile, admin, support, and install actions now open from the avatar in the header (replacing the bottom "More" tab).
-   Admin Members: **Hide emails** toggle for screen sharing, and an activity dot on student avatars (green = session in last 30 days).
-   Admin Remove button on student profile pages — a shortcut for taking a student off the roster without going back to the list.
-   Faster phone-clip uploads: chunked multipart now kicks in at 20 MB with parallel presigning.

### April 2026

-   AI review (powered by Twelve Labs): on-demand video analysis that suggests coaching notes you can edit, keep, or delete.
-   Help center refresh: improved search with highlighted snippets and keyboard navigation.
-   Added keyboard shortcuts for faster help-center navigation — press <kbd>?</kbd> to see them all.
-   Print-friendly styles for saving pages offline.
-   Better accessibility: skip-to-content, improved ARIA labels, focus management.
-   Developer API page updated with the internal API reference link and a clearer note that a public API is not available today.

### March 2026

-   Keyboard shortcuts during playback: **Space/K** (play/pause), **J/L** or arrow keys (skip 10s), **F** (fullscreen), **M** (mute), **↑/↓** (volume).
-   Timeline note markers with hover preview.
-   Playback speed controls from 0.5x to 2x.
-   Chunked parallel upload with automatic retry.
-   Real-time speed and ETA display during upload.
